# Портфолио Senior Delivery Manager

Одностраничный сайт на React, TypeScript и Vite.

## Публикация

Сайт автоматически публикуется на GitHub Pages при push в ветку `main`:
[yulmianissa.github.io/portfolio](https://yulmianissa.github.io/portfolio/).

## Запуск

```sh
npm install
npm run dev
```

Для проверки production-сборки:

```sh
npm run build
npm run preview
```

Контакты и ссылки на профили указаны в `src/App.tsx`.
